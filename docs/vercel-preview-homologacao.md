# Publicação de homologação na Vercel

Esta atualização foi criada exclusivamente na ramificação `homologacao-geral` após a conexão GitHub ↔ Vercel, para solicitar uma nova implantação **Preview**. Não mesclar na `main` para publicar a homologação.

Rotas previstas após o Preview ficar disponível:

- `/homologacao`: experiência demonstrativa sem gravações.
- `/homologacao/cliente-real`: experiência conectada ao Supabase real, incluindo solicitações reais de agendamento.
- `/homologacao/pacotes`: aprovação restrita a perfis de gestão.

Apenas a confirmação **Ready** no painel Deployments da Vercel comprova a publicação. O build do GitHub, isoladamente, não comprova a publicação na Vercel.
